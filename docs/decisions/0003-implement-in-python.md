# 0003: 実装言語に Python を採用する

## 状態

承認済み (2026-08-11)

## 文脈

[0002](0002-two-stage-fetch-csv-then-detail.md) で決めた取得方式が要求するのは
主に次の 4 つで、いずれも特別な性能要件を伴わない。

- CSRF トークンと Cookie を維持したフォーム POST
- HTML からの構造化データ抽出 (詳細ページの項目と解説文)
- CSV (UTF-8 BOM 付き) の読み取りと JSON Lines の書き出し
- GitHub Actions 上での定期実行

## 決定

Python で実装する。

HTML パース・文字コード処理・CSV/JSON の取り回しが標準ライブラリと
定番パッケージで素直に書け、セッション管理も一般的な作法が確立している
ことを重視した。単一バイナリでの配布や高い並行性は、このリポジトリの
用途では利点にならない (アクセスマナーとして逐次取得するため)。

## 影響

- CI (`.github/workflows/ci.yml`)、Dependabot (ecosystem: pip)、
  テストディレクトリ (`tests/`) を Python 前提で整備する。これらは
  実装言語が未定であることを理由に repo-audit で保留していた項目にあたる
- 検証コマンドが決まるので CLAUDE.md の「検証コマンド」節を埋められる
- 依存パッケージの選定 (HTTP クライアント・HTML パーサ) は実装時に決める。
  この ADR では言語のみを決め、ライブラリ構成は縛らない
