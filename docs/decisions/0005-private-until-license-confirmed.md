# 0005: 文化庁への確認が取れるまでリポジトリを private に保つ

## 状態

承認済み (2026-08-11)

## 文脈

2026-08-11 に利用条件を調査した (詳細は Issue #1 のコメント)。

- データベースの利用規約ページは、**文字情報**は出典を記載すれば自由に
  利用できるとし、**画像**は第三者が権利を有するため作品毎に個別の許諾が
  必要としている
- 参照先の文部科学省ウェブサイト利用規約は、政府標準利用規約 (第2.0版)
  に準拠し CC BY 4.0 と互換である旨を明記している。商用利用も可
- クローリングや自動アクセスを禁じる記述は、いずれのページにも無い。
  `robots.txt` は存在しない (HTTP 404)
- **未解決の矛盾**: 文部科学省ウェブサイト利用規約の別紙には、事前に
  担当課への問合せが必要なコンテンツとして「国指定文化財等データベース」が
  名指しで挙げられている。データベース側の利用規約ページの記述
  (文字情報は出典表示で自由利用) と整合せず、どちらが優先するかを示す
  明文は見つからなかった

公開してから撤回するのは実質的に不可逆である一方、確認が取れてから公開
するのはいつでもできる。

## 決定

- リポジトリは当面 **private** とする。文化庁への問合せで再配布の可否が
  確認できた時点で public 化を判断する
- **画像は取得・再配布の対象外**とする。個別許諾が明示されているため、
  規約の矛盾の帰結にかかわらず対象外で確定とする
- public 化する場合は、出典表記と加工した旨の併記を必須とする。
  文部科学省ウェブサイト利用規約の書式に沿うと次の形になる

  ```
  出典：「国指定文化財等データベース」（文化庁）
  （https://kunishitei.bunka.go.jp/）（YYYY年M月D日に利用）
  上記を加工して作成
  ```

- LICENSE に「CC BY」とだけ書かない。データベース側が画像について別条件を
  上乗せしている構造のため、出典表示と文化庁の規約へのリンクを示す形にする

## 影響

- データリポジトリ ([0001](0001-split-repositories-by-heritage-type.md)) も
  同じ方針に従う。公開して使ってもらう形にできるかは問合せの結果次第
- 文化庁への問合せは Issue #1 の残タスクとして管理する
- クローラーの実装では画像 URL の取得・保存を行わない。添付ファイルの
  「有無」はメタデータとして記録してよいが、実体は取得しない
- 編集・加工した情報を、国が作成したかのような態様で公表しないこと
  (文部科学省ウェブサイト利用規約が明示的に禁じている)
