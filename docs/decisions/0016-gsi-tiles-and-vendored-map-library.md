# 0016: 地図は地理院タイルを既定とし、ライブラリは同梱する

## 状態

承認済み (2026-08-12)

## 文脈

[0015](0015-single-cross-type-site-on-pages.md) で決めたサイトの中心は地図になる。
出力の 23,855 行のうち約 98% に緯度経度があり、**それが「一覧を見る」以上の価値を
出せる唯一の軸**だからでもある ([0007](0007-redistribute-text-with-attribution.md)
により画像は持てないので、視覚的な手がかりは地図しかない)。

無料で使えるタイルの選択肢は実質 2 つで、条件が大きく違う (いずれも 2026-08-12 に
規約の原文を確認した)。

**国土地理院の地理院タイル** — [一覧ページ](https://maps.gsi.go.jp/development/ichiran.html)
が、ウェブサイトからリアルタイムに読み込む利用は「出典の明示のみで申請不要」と
明記している。[コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)
は公共データ利用規約 (第 1.0 版) で、政府標準利用規約に準拠し CC BY 4.0 と互換。
出典は「国土地理院」または「地理院タイル」等と記載し、一覧ページへのリンクを
付けることが求められる。[出典の記載](https://www.gsi.go.jp/LAW/2930-meizi.html)
は、測量成果が画面に表示されている間は常に見えるように示すことを求めている。
標準地図・淡色地図ともズームレベルは 5〜18。

**OpenStreetMap の共有タイル** —
[Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) は、
タイルサーバが寄付で賄われた限られた資源であること、可用性は最善努力で SLA も
保証も無いこと、サービスを劣化させる使い方は予告なく遮断しうることを明記している。
利用者が実際に見ている範囲以外を先読みすることは禁止で、帰属表示を隠すことも
できない。ポリシー自身が、タイルの URL をコードに埋め込まず切り替え可能に
しておくことを勧めている。

ライブラリの読み込み方にも選択がある。CDN から読めばリポジトリは軽くなるが、
**閲覧者のブラウザが第三者のオリジンへ接続し、そこへ IP が渡る**。10 個を超える
データリポジトリを抱えるプロジェクトで、実行時の依存先を増やす判断でもある。

## 決定

- **既定のタイルは地理院タイル**とし、淡色地図を初期表示にする。2 万を超える点を
  重ねるので、地物の描き込みが少ない淡色の方が読める。`minZoom` は 5 とする
  (それより引いたタイルは存在しない)
- **出典は地図が見えている間ずっと表示する。**「地理院タイル」の文字と、規約が
  指定する一覧ページへのリンクを、折りたたみやトグルの内側に入れない
- **タイルを先読みしない。事前に取得して自前で配らない。**リアルタイムに読み込む
  利用だから申請が要らないのであって、取得して再配布すればその前提から外れる。
  OSM 側でも先読みは明確に禁止されている
- **OSM の共有タイルは既定にしない。**規約上は通常の対話的な閲覧なら使えるが、
  寄付で運営され予告なく遮断されうる資源である。日本国内に限ったデータに対して
  公的機関が維持する代替がある以上、そちらを使うのが筋。切り替え先としては残し、
  **タイルの URL はコード中の 1 箇所に置く** (使うときは
  `© OpenStreetMap contributors` の表示が要る)
- **API キーが要るタイル (Mapbox・MapTiler・Google) は検討しない。**無料で
  完結するという前提に合わない
- **地図ライブラリは CDN から読まず、リポジトリに同梱する。**閲覧者の接続先を
  増やさず、ローカルでもタイル以外はそのまま動く (= 外部依存がタイルだけである
  ことを目で確かめられる)。バージョンは内容で固定され、ライセンス表記も同梱する

## 影響

- 地図の見た目と操作は日本国内向けに寄る。国外の地物は表示されないが、対象データが
  国内限定なので実害はない
- 出典の表示義務が 3 つ並ぶ (データ = 文化庁、地図 = 国土地理院、そして非公式で
  ある旨)。これらは**混ぜずに別々に示す**。国が作成したかのような態様を避ける
  必要は [0007](0007-redistribute-text-with-attribution.md) から続く
- 過大な負荷を与えれば遮断されうるので、先読みや自動的な連続取得を足すときは
  この ADR に戻って考え直す
- 規約は変わりうる。[0007](0007-redistribute-text-with-attribution.md) が決めた
  「公開時と以後年 1 回は原文を読み直す」対象に、地理院の規約も加える
