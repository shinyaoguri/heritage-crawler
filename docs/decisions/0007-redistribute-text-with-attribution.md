# 0007: 文字情報は出典表示のもとで再配布し、リポジトリを public にできる

## 状態

承認済み (2026-08-11)。
[0005](0005-private-until-license-confirmed.md) を置換する。

## 文脈

[0005](0005-private-until-license-confirmed.md) は、データベース側の利用規約
(文字情報は出典表示で自由利用) と、参照先である文部科学省ウェブサイト利用規約の
別紙 (「国指定文化財等データベース」を事前問合せが必要なコンテンツとして名指し)
が整合せず、どちらが優先するかを示す明文が見つからないとして、リポジトリを
private に保っていた。

2026-08-11 に規約の原文を再確認したところ、**優先関係を定める明文が存在した**。
0005 はこれを見落としていた。

- 文部科学省ウェブサイト利用規約 1. の注記:
  「（注）上記ドメインを含むウェブサイトについて、利用規約を別に定めている場合は、
  当該利用規約が適用されます。」
  `kunishitei.bunka.go.jp` は同規約が列挙する `bunka.go.jp` ドメインの配下であり、
  かつ独自の利用規約ページ (https://kunishitei.bunka.go.jp/top/policy) を持つ。
  よって**データベース側の利用規約が適用される**

- 別紙の名指しも、前置きまで読むと矛盾しない。別紙 2) の対象は
  「第三者が権利を有していても、権利者からの要望や装飾目的のため、権利者に
  ついて表示していません」というコンテンツであり、このデータベースで第三者が
  権利を有するのは**画像**である (データベース側の利用規約が明示している)。
  文字情報は文化庁が作成した指定情報であり、別紙 2) の対象に当たらない

あわせて確認した事実:

- データベース側の利用規約 — 文字情報は「出典を記載の上、自由にご利用ください」。
  画像は「第三者が権利を有しているものがあるため、作品毎に個別の許諾が必要」
- 文部科学省ウェブサイト利用規約は政府標準利用規約 (第2.0版) に準拠し、
  **CC BY 4.0 と互換**である旨を明記している。商用利用・翻案も可
- 同規約の最終改正は令和8年6月16日 (2026-08-11 時点)。
  規約自体が「今後変更される可能性があります」と述べている

## 決定

- **文字情報の再配布は、出典表示を伴えば行える。** 文字情報について文化庁への
  事前問合せは要しない。これに伴い 0005 の「問合せが取れるまで private」は解除し、
  このリポジトリおよび出力先のデータリポジトリは public にできる
- **画像は引き続き取得・再配布の対象外**とする (0005 から変更なし)。作品毎の
  個別許諾が必要であり、規模的にも現実的でない。添付ファイルの「有無」は
  メタデータとして記録してよいが、実体は取得しない
- **ライセンス表記は 2 層に分ける。** コードとデータで条件が異なるため、
  1 つのライセンスに丸めない
  - **コード** (このリポジトリ) — MIT。`LICENSE` に置く
  - **データ** (出力先リポジトリ、[0001](0001-split-repositories-by-heritage-type.md)) —
    文化庁の利用規約に従う。データリポジトリの `LICENSE` にはコード用のライセンスを
    置かず、出典表示と規約へのリンクを示す。CC BY と互換である旨は補足として
    書いてよいが、「CC BY である」と言い切らない (画像について別条件が
    上乗せされている構造のため)
- **出典表記の書式**は文部科学省ウェブサイト利用規約の記載例に沿う。データ
  リポジトリの README と LICENSE、および JSON Lines を配布するリリースに含める

  ```
  出典：「国指定文化財等データベース」（文化庁）
  （https://kunishitei.bunka.go.jp/）（YYYY年M月D日に利用）
  上記を加工して作成
  ```

  利用日は取得日 (クロール実施日) を書く。加工した旨を必ず併記する
- 編集・加工した情報を、国が作成したかのような態様で公表しない
  (文部科学省ウェブサイト利用規約が明示的に禁じている)

## 影響

- このリポジトリに `LICENSE` (MIT) を置き、`README.md` にデータの出典と利用条件を
  記載する。`pyproject.toml` にも license を明記する
- データリポジトリの LICENSE / README 整備を Issue #9 の受け入れ条件に加える。
  データリポジトリはまだ存在しないため、書式はこの ADR を正本とする
- 文化庁への問合せを追っていた
  [#11](https://github.com/shinyaoguri/heritage-crawler/issues/11) は、文字情報に
  ついては不要になったためクローズする。画像を扱いたくなった場合は改めて起票する
- リポジトリの可視性を private から public へ変える判断ができるようになった。
  実際の切り替えは不可逆に近いため、内容が公開に耐える状態になった時点で行う
- 規約は変更されうる。参照ドリフト検査 (`scripts/check-freshness.sh`) は外部
  サイトへアクセスしない方針のため自動検知の対象にしない。データリポジトリの
  公開時と、以降は年 1 回程度、規約の原文を読み直す
