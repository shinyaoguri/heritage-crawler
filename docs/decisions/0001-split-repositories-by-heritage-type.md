# 0001: 文化財の種別ごとにリポジトリを分けて code4heritage org で管理する

## 状態

承認済み (2026-08-11)。ただし分割の単位とこのリポの位置付けは Issue #1 で議論中

## 文脈

国指定文化財等データベースは建造物以外にも多数の種別 (美術工芸品・
史跡名勝天然記念物など) を持ち、種別ごとにデータ項目・取得方法・
更新頻度が異なる。単一リポジトリに全種別を詰め込むと、データ量と
関心事が混ざり、履歴も追いにくくなる。

## 決定

文化財の種別ごとにリポジトリを分け、code4heritage organization で
管理する。このリポジトリ (heritage-crawler) は建造物に関連した
データの抽出から始める。

未決事項 (Issue #1 で議論):

- 分割の単位 (データベース上の「種別」とリポの 1:1 対応にするか)
- クローラー本体とデータリポジトリを分離するか

## 影響

- 各種別のデータは独立した履歴を持ち、リポ単位で公開・共有を判断できる
- 種別横断の処理 (共通クローラーロジック) の置き場は未決事項の結論に
  依存する
- 未決事項が決まったらこの ADR を更新するか、置換する ADR を起こす
